# Mi Piace Rengo - Trattoria Italiana

Sitio web oficial, carta gastronómica digital y sistema de pedidos y reservas online para **Mi Piace Rengo**, auténtica trattoria italiana ubicada en Rengo, Región de O'Higgins, Chile (desde 2014).

## 🍕 Características Principales

- **Diseño Moderno & Elegante**: Desarrollado con Tailwind CSS y tipografías clásicas italianas (`Cinzel`, `Playfair Display`, `Great Vibes`).
- **Galería Fotográfica Real**: Carrusel dinámico con fotos reales del local y platos de autor.
- **Carta Digital Interactiva**:
  - Filtros por categoría (Pizzas, Pastas, Carnes & Risottos, Picadas, Burgers, Postres y Bebestibles).
  - Platos destacados con fotografías.
  - Carrito de compras en tiempo real con cálculo automático de delivery y retiro en local.
  - Integración directa con **WhatsApp** para recepción de pedidos con detalle completo.
- **Sistema de Reservas**: Formulario para agendar mesa con fecha, hora, comensales y requerimientos especiales con confirmación por WhatsApp.
- **Reseñas de Clientes**: Carrusel rotativo de opiniones reales de Google Maps (4.5 / 5.0 con más de 710 reseñas).
- **Ubicación & Horarios**: Mapa interactivo de Google Maps de José Bisquertt 284, Loc 4, Rengo.

## 🚀 Tecnologías

- HTML5 semántico
- Tailwind CSS (CDN)
- FontAwesome 6
- Vanilla JavaScript
- Optimizado para dispositivos móviles y escritorio

José Bisquertt 284, Local 4, Rengo, Región de O'Higgins, Chile.
